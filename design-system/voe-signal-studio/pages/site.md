# VOE Club Platform — Site Override

This file overrides the original experimental landing-page direction for all production pages.

## Direction

- Product: official student-led creative community website.
- Style: modern editorial structure with creative-studio energy.
- Layout: 12-column grid, generous whitespace, strong content hierarchy.
- Motion: purposeful 180–450ms transitions; no continuous decorative movement.
- Corners: restrained 12–24px rounding for functional surfaces.

## Palette

- Obsidian: `#0B0B0F`
- Raised ink: `#18181F`
- Editorial paper: `#F7F5ED`
- Electric violet: `#6D3DF5`
- Signal lime: `#C7F464`
- Warm amber: `#F4B860`

All primary foreground/background pairings must meet WCAG AA.

## Typography

- Display/editorial: Instrument Serif.
- UI/body: Manrope.
- Mono labels: DM Mono.

## Content rules

- Never publish invented dates, statistics, achievements, testimonials or partnerships.
- Missing factual content receives an honest empty state or is omitted.
- Calls to action use concrete labels such as Join VOE, Explore Wings and Contact the Team.
